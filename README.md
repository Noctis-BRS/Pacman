# Pacman

Bài tập thực hành lập trình game Pacman bằng HTML, CSS và JavaScript.

## Công nghệ
- HTML5
- CSS3
- JavaScript
- Canvas

## Cách chơi
- Arrow Up: Di chuyển lên
- Arrow Down: Di chuyển xuống
- Arrow Left: Di chuyển trái
- Arrow Right: Di chuyển phải
